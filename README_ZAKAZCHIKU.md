## 1. Логотип (обязательно)

Присланный логотип VIREO положите в папку:
```
vireo-site/img/logo.svg
```

Логотип уже подключён на всех страницах (путь `img/logo.svg`). Если файл не загрузится, отобразится текстовый вариант.

Требования к логотипу: тонкий, в букве «O» листок, охранное поле не менее ширины двух букв «R».

## 2. Фото аппаратов и препаратов

Скачайте реальные фото с сайта-референса: https://fotodinamika.ru/kontakty/

Замените SVG-заглушки в папке `img/`:

| Файл | Что должно быть |
|------|-----------------|
| `img/fdt-placeholder.svg` | Аппарат ФДТ (геро-блок главной) |
| `img/apparat-1.svg`, `apparat-2.svg`, `apparat-3.svg` | Фото аппаратов (все ракурсы) |
| `img/preparat-1.svg`, `preparat-2.svg`, `preparat-3.svg` | Фото препаратов (тубы, флаконы, дозаторы) |
| `img/expert-placeholder.svg` | Фото доктора Карповой |

Рекомендуемый формат: JPG или WebP, сжатые под веб. Обновите пути `src` в HTML-файлах, если измените имена.
