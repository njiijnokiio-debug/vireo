## 3. Инструкции (PDF)

На fotodinamika.ru инструкции в открытом доступе не опубликованы, поэтому кнопки «Скачать» заменены на «Запросить»: они ведут на страницу «Контакты». На странице инструкций все документы помечены «PDF · предоставляется по запросу».

Когда пришлёте PDF-файлы:
1. Положите их в папку `files/` (например, `files/instruction-quattro.pdf`).
2. В `instruktsii.html`, `apparat.html`, `preparat.html` замените ссылки `href="kontakty.html"` на путь к файлу и добавьте атрибут `download`.
3. В подписи документа замените «PDF · предоставляется по запросу» на объём файла.
